Descripción del videojuego

Este repositorio contiene el desarrollo de nuestro proyecto de videojuego.

Nombre del juego: Shaolin Jumper

Género: Acción, comedia, Plataformas 2D

Descripción: Un joven fan de las peliculas de Chun Jaakie, comenzó a tener visiones y alucinaciones, creyendose que se encuentra en una de sus pelicula y que debía recorrer el camino del monje para conseguir la cinta perdida de su idolo, Enfrentandose a enemigos.

Herramientas
Motor de desarrollo: Unity
Control de versiones: Git y GitHub
Cómo colaborar
Aceptar la invitación al repositorio.
Descargar o clonar el proyecto.
Crear una rama para trabajar en cada tarea.
Guardar los cambios mediante commits descriptivos.
Subir los cambios a GitHub y abrir una Pull Request para revisar el trabajo.
Normas del equipo
Mantener una comunicación clara.
No sobrescribir el trabajo de otros compañeros.
No subir contraseñas ni archivos temporales innecesarios.
Revisar los cambios antes de integrarlos en la rama principal.
